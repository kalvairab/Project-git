# Extraction Run Prototype

This is a small browser-based extraction shooter prototype built for quick testing and iteration.

## What it includes
- WASD movement
- Mouse aiming
- Click-to-shoot combat
- Enemy AI chase behavior
- Loot pickup system
- Extraction zone win condition
- Restart flow

## How to run
1. Open `index.html` in a browser, or
2. Serve the folder locally with a simple static server, for example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls
- W / A / S / D: Move
- Mouse: Aim
- Left click: Fire
- R: Restart

## Project structure
- `index.html` — main page
- `style.css` — visual styling
- `game.js` — gameplay logic

This is a lightweight prototype, intended as a starting point for a larger extraction shooter project.
